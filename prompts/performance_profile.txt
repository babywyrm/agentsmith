  Look for: Nested loops over collections, linear search where hash lookup works, sorting without need, repeated computation of same value, regex backtracking (ReDoS)

MEMORY & RESOURCE MANAGEMENT (Impact: HIGH)
  Priority: Memory leaks, unbounded caches, large object allocation in hot paths
  Look for: Growing collections without eviction, loading entire files into memory, large string concatenation in loops, no connection pooling, unclosed resources
  Severity: CRITICAL for memory leaks in long-running processes, HIGH for unbounded growth

I/O & NETWORK (Impact: HIGH)
  Priority: Blocking I/O on main thread, synchronous external calls, no timeouts
  Look for: Synchronous HTTP calls in async contexts, file I/O without buffering, missing connection timeouts, no retry with backoff, serial external calls that could be parallel
  Severity: CRITICAL for blocking main thread (Node.js event loop, Python asyncio), HIGH for missing timeouts

CONCURRENCY & PARALLELISM (Impact: MEDIUM-HIGH)
  Priority: Lock contention, thread pool exhaustion, underutilized parallelism
  Look for: Global locks on hot paths, unbounded thread creation, sequential processing of independent tasks, shared mutable state requiring synchronization
  Severity: HIGH for lock contention in high-throughput paths

CACHING (Impact: MEDIUM)
  Priority: Missing caching for expensive operations, cache invalidation issues
  Look for: Repeated identical computations/queries, no caching layer for external API calls, unbounded caches without TTL, stale cache without invalidation strategy
