SUPPLY CHAIN SECURITY (CWE-1357, CWE-829)

SECRETS MANAGEMENT (CWE-798, CWE-312)
  Priority: Hardcoded secrets, env var leaks, insecure secret storage, secrets in logs
  Look for: API keys, tokens, passwords in source; secrets passed via CLI args (visible in ps); secrets logged in error messages; .env files without .gitignore
  Severity: CRITICAL for hardcoded production credentials, HIGH for secrets in logs

ZERO TRUST PRINCIPLES
  Priority: Service-to-service auth, least privilege, explicit verification
  Look for: Internal APIs without auth ("trusted network" assumptions), overly broad IAM roles, missing mTLS between services, CORS wildcards
  Severity: HIGH if internal services accept unauthenticated requests

CONTAINER SECURITY (CWE-250)
  Priority: Running as root, large attack surface images, missing health checks
  Look for: USER root or no USER directive in Dockerfile, apt-get install without cleanup, COPY . . (leaking secrets into image), privileged containers
  Severity: HIGH for containers running as root with network access

API SECURITY (CWE-284, CWE-918)
  Priority: Missing rate limiting, broken authentication, mass assignment, BOLA/IDOR
  Look for: Endpoints without auth middleware, no rate limiter, accepting arbitrary fields from request body, direct object references without ownership checks
  Severity: CRITICAL for auth bypass, HIGH for missing rate limiting on sensitive endpoints

INFRASTRUCTURE AS CODE
  Priority: Overly permissive IAM, public S3 buckets, open security groups, no encryption
  Look for: iam:*, 0.0.0.0/0 ingress, public-read ACLs, unencrypted storage, no VPC isolation
  Severity: CRITICAL for public data stores, HIGH for overly permissive IAM

CI/CD SECURITY
  Priority: Secret injection in pipelines, unsigned artifacts, script injection
  Look for: Secrets in workflow files, curl | bash patterns, unpinned GitHub Actions, no artifact signing
  Severity: HIGH for pipeline secret exposure, MEDIUM for unpinned actions

SERVERLESS SECURITY
  Priority: Over-permissioned functions, event injection, insecure deserialization
